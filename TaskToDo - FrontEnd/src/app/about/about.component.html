Welcome to Task To-Do

Task To-Do is a simple and intuitive Todo management application designed to help you stay organized and productive.

✨ Features

  • User Authentication: Secure login and registration system.
  • Add Todos: Create new tasks with title and description.
  • View Todos: See all your tasks in a clean, responsive table format.
  • Update Todos: Edit your existing tasks easily.
  • Delete Todos: Remove tasks you no longer need.
  • Logout: Securely sign out of your account anytime.

🚀 How It Works

  1. Create an account or log in using your credentials.
  2. Start by adding your first task using the "Add Todo" button.
  3. You can update or delete tasks from the dashboard anytime.
  4. Stay productive and manage your day with ease!

Built with Angular and Spring Boot 💻
